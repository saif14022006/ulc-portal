# ULC Toolkit — Google Play listing assets

## Upload these files in Play Console → Store listing

### App icon (required)
- play-icon-512.png  (512 x 512)

### Feature graphic (required)
- play-feature-1024x500.png  (1024 x 500)
- Optional alt: play-feature-alt-1024x500.png

### Phone screenshots (required — upload at least 2; 4 recommended)
- phone-01-welcome.png
- phone-02-features.png
- phone-03-cover.png
- phone-04-teacher.png
All are 1080 x 1920 (9:16).

### Text
- short-description.txt  (paste into Short description)
- full-description.txt   (paste into Full description)

### Optional (skip for now)
- Video / Tablet / Chromebook / Android XR — leave empty
